# StockFlow

StockFlow is a simple desktop-based Inventory Management System developed using Python, Tkinter, and MySQL.

It helps manage products, track stock movement, and view transaction history through a simple user-friendly interface.

## Features

- User Login
- Dashboard
- Add Product
- View Products
- Update Product
- Delete Product
- Search Product
- Stock IN
- Stock OUT
- Transaction History

## Technologies Used

- Python
- Tkinter
- MySQL
- MySQL Connector
- bcrypt
